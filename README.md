# RTES-Projects-10885

Αποθετήριο εργασιών για το μάθημα "Ενσωματωμένα Συστήματα Πραγματικού Χρόνου" (ΕΣΠΧ).

## ergasia_0: K-Nearest Neighbors (KNN) με pthreads
Ατομική Εργασία 0. Υλοποίηση του αλγορίθμου K-Nearest Neighbors στη γλώσσα C.

**Περιεχόμενα φακέλου:**
- `knn_pthreads.c`: Ο πηγαίος κώδικας του αλγορίθμου, Παράγει και ένα output.mat αρχείο για σύγκριση.
- `input.mat`: Αρχείο δεδομένων για γρήγορη δοκιμή του προγράμματος.
- `plot_results.m`: MATLAB script για την οπτικοποίηση των αποτελεσμάτων.
- `Makefile`: Παράγει το εκτελέσιμο αρχείο με όνομα `knn_pthreads`.

**Οδηγίες Εκτέλεσης (Linux/Ubuntu):**
Αφού κάνετε compile με την εντολή `make`, μπορείτε να τρέξετε το πρόγραμμα γράφοντας στο τερματικό:
```
./knn_pthreads <αρχείο.mat> <k>
```
Για παράδειγμα, εάν θέλετε να τρέξετε τον κώδικα για τα δεδομένα του `input.mat` ψάχνοντας για `k = 5` γείτονες:
```
./knn_pthreads input.mat 5
```
